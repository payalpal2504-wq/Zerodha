# Zerodha Frontend — Vite + React

## Start the project on Windows

1. Install a supported Node.js version (Node 22.12+ recommended for Vite 7).
2. Extract the project ZIP.
3. Open the extracted `frontend` folder in VS Code.
4. Open **Terminal → New Terminal**.
5. Run:

   ```powershell
   npm install
   npm run dev
   ```

6. Open the localhost URL printed in the terminal (usually `http://localhost:5173`).

## Other commands

```powershell
npm run build
npm run preview
```

See `VITE_MIGRATION_GUIDE.md` for the migration details and troubleshooting notes.
